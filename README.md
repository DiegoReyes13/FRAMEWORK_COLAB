Apunta

Prototipo web navegable(solo Front-End: HTML5, CSS3) de Apunta, una plataforma de estudio donde estudiantes y profesores comparten, consultan y califican material académico, con herramientas de repaso activo (minijuegos) y de organización/bienestar (calendario, temporizador, calculadora de promedio).
